# NIRcannabis (deprecated)

**Deprecated.** `NIRcannabis` was renamed to
[`proximateCannabis`](https://buchi-labortechnik-ag.github.io/proximetricsR/reference/proximateCannabis.md)
in proximetricsR 0.7.1, for consistency with the
[`proxiscoutCannabis`](https://buchi-labortechnik-ag.github.io/proximetricsR/reference/proxiscoutCannabis.md)
dataset. It is kept as an exact copy of
[`proximateCannabis`](https://buchi-labortechnik-ag.github.io/proximetricsR/reference/proximateCannabis.md)
so that existing code keeps working, and will be removed in a future
release. Please use
[`proximateCannabis`](https://buchi-labortechnik-ag.github.io/proximetricsR/reference/proximateCannabis.md)
instead.

## Usage

``` r
data("NIRcannabis")
```

## Format

A `data.frame` containing 80 observations of four response variables,
with their corresponding spectral data.
